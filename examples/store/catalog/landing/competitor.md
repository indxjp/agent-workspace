# ja

## headline

競合の公開情報と自社の比較表を毎週突き合わせ、変わった行を根拠の発表と公表日つきで一覧にする。

## audience

法人営業の担当者、競合情報をまとめる営業企画やマーケティングの担当者

## problem

競合の料金改定や新機能の発表を、担当者が各社のサイトで見回り、比較表を手で直している。どの発表にもとづいて値を変えたのかが残らず、表が古いまま商談で使われることもある。

## steps

1. [] 受け取る：毎週の決まった時刻に、自社の比較表をもとに作業を始める。
2. [] 調べる：競合各社の料金改定や新機能の発表を、公開情報から読む。
3. [] 判断する：比較表の行ごとに、より新しい発表で値が変わったものを選び、変更前と変更後を添える。
4. [] 人が確認する：レポートを保存する前に、担当者の承認を待つ。
5. [] 書き込む：承認された一回の保存で、その週のレポートをフォルダに書く。

## outputs

- 変わった行ごとに、競合・項目・変更前・変更後・根拠の発表・公表日を並べた週次レポート（Markdown）
- 比較表の項目に当たらない発表の一覧
- どの時点の公開情報にもとづくかを示す一行

## faq

### 自社の比較表を使えますか？

使えます。競合・項目・値・根拠の発表を一行ずつ書いた比較表のファイルを置くと、その表と公開情報を突き合わせます。

### 比較表そのものを書き換えますか？

書き換えません。変わった行をレポートにまとめるまでで、表を直すかどうかは担当者が決めます。

### 市場シェアや売れ行きも教えてくれますか？

教えません。公開情報に書かれた値だけを伝え、どの製品が安いか、売れているかといった評価や予測はしません。

### 公開情報はいつの時点のものですか？

デモでは、架空の競合各社の発表の日付つきスナップショットを読みます。レポートには、どの時点の公開情報にもとづくかを必ず書きます。導入後は、設定した各社の公開情報を読みます。

## limits

- 市場シェア・売上の順位・将来の動きを推測しない。
- 比較表のファイルを書き換えない。
- 競合や顧客に連絡しない。
- 承認なしにレポートを保存しない。

# en

## headline

Checks your comparison table against competitors' public releases each week, and lists the rows that changed with the release and its date.

## audience

Account managers in B2B sales, and sales operations or marketing staff who keep competitor information

## problem

Staff look through each competitor's website for price changes and new features, and fix the comparison table by hand. Which release a value came from is not recorded, and an out-of-date table sometimes ends up in a sales meeting.

## steps

1. [] Receive: starts at a set time each week, from your comparison table.
2. [] Look up: reads competitors' price changes and feature announcements from public sources.
3. [] Decide: picks each table row whose value a newer release changed, with the value before and after.
4. [] A person confirms: waits for approval before saving the report.
5. [] Write: writes the week's report to the folder in the one approved save.

## outputs

- A weekly report (Markdown): for each changed row, the competitor, item, value before and after, the release it rests on and its date
- A list of the releases that change no row of the table
- A line saying the date the public sources stand as of

## faq

### Can it use our own comparison table?

Yes. Put a table file with one row per competitor and item, its value and the release it came from, and it checks that table against the public sources.

### Does it change the table itself?

No. It reports the changed rows; whether to update the table is for a person to decide.

### Will it tell us market shares or who sells best?

No. It reports only the values the public releases state, and makes no judgement or forecast about which product is cheaper or sells more.

### How current are the public sources?

The demo reads a dated snapshot of fictional competitors' releases. Every report says the date its sources stand as of. Once installed, it reads the competitors' public sources you configure.

## limits

- Never guesses market shares, sales rankings or a competitor's next move.
- Never changes the comparison table file.
- Never contacts a competitor or a customer.
- Never saves a report without approval.
