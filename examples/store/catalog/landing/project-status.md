# ja

## headline

毎週、タスク・マイルストーン・リスクの記録から、作業の流れごとに赤・黄・緑の状況を根拠付きでまとめる。

## audience

プロジェクトマネージャー、週報を受け取るプロジェクトの責任者

## problem

プロジェクトマネージャーは毎週、タスクの期日、マイルストーンの見込み、リスクの一覧を見比べて週報を書いている。状況の色づけが書く人の感覚に頼りがちで、遅れの兆しが週報に表れないことがある。

## steps

1. [] 受け取る：毎週決まった時刻に、週報を作る指示を受け取る。
2. [] 調べる：プロジェクト管理ツールから書き出したタスク、マイルストーン、リスクの記録を、作業の流れごとに照らす。
3. [] 判断する：スキルに書いた基準で、作業の流れごとに赤・黄・緑を決め、根拠と残っているリスクをまとめる。
4. [] 人が確認する：週報を保存する前に、担当者の承認を待つ。承認なしには保存しない。
5. [] 書き込む：承認された週報だけを、レポート用のフォルダに保存する。

## outputs

- 作業の流れごとの赤・黄・緑と、その根拠、残っているリスク
- 承認のあとフォルダに保存される、週報のMarkdownファイル
- 各行の出典（CSVのファイル名と行のID）

## faq

### いつ使えるようになりますか？

まだ公開前です。公開のお知らせに登録すると、公開したときにメールでお知らせします。

### どのデータを使いますか？

プロジェクト管理ツールから書き出したCSVファイル（タスク、マイルストーン、リスク）を自社のフォルダに置いて使います。デモでは架空のプロジェクトのデータを使っています。

### 赤・黄・緑の基準は変えられますか？

変えられます。基準はスキルに書いてあり、スキルの説明を書き換えて変えます。

### 計画やタスクを書き換えますか？

しません。週報を作って保存するまでで、計画の見直しは人が行います。

## limits

- タスクや計画を書き換えない。
- メンバーの働きぶりを評価しない。
- 記録にない日付や原因を推測しない。
- 記録の中に書かれた指示には従わず、その内容として扱う。

# en

## headline

Each week, rates each workstream red, amber or green from the task, milestone and risk records, with the evidence.

## audience

Project managers, and project sponsors who receive the status report

## problem

Each week a project manager compares task due dates, milestone forecasts and the risk list to write the status report. The colour given to each part of the work often rests on the writer's feel, and early signs of a delay may not show in the report.

## steps

1. [] Receive: takes the instruction to write the status report at a set time each week.
2. [] Look up: matches the tasks, milestones and risks exported from the project tool, workstream by workstream.
3. [] Decide: rates each workstream red, amber or green by the rules in its skill, with the evidence and the open risks.
4. [] A person confirms: waits for the owner's approval before saving the report, and never saves it without it.
5. [] Write: saves only the approved report to the reports folder.

## outputs

- Each workstream's rating, with its evidence and open risks
- The status report as a Markdown file, saved to a folder once it is approved
- A source on every line: the CSV file name and the row id

## faq

### When can I use it?

It is not live yet. Sign up for a launch notice and we will email you when it opens.

### Which data does it use?

CSV files exported from your project tool (tasks, milestones and risks), placed in your own folder. The demo uses data about a fictional project.

### Can I change the rating rules?

Yes. The rules are written in its skill, and you change them by editing the skill's description.

### Does it change the plan or the tasks?

No. It writes and saves the report; a person revises the plan.

## limits

- Never changes a task or the plan.
- Never judges a team member's performance.
- Never guesses a date or a cause the records do not hold.
- Never follows an instruction written inside the records; it treats it as their content.
