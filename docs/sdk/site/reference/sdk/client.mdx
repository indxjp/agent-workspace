### Methods

Operations on the client itself, belonging to no resource family.

#### me

Who this credential is: `{ principalId, kind, role, workspaceId, userId, label }`.

Every consumer's first call. An API key is bound to one workspace and carries no membership
to list, so this is the only way it can name the workspace and role it was authorised under;
a session caller additionally learns its `userId` and a human label. `userId` is `null` for
exactly an API-key principal.

## ClientAuth

How the client proves who it is.

`api-key` sends a workspace API key (`ak_live_…`) as `Authorization: Bearer`; it is the
credential a customer's backend holds. `session` sends nothing and asks `fetch` to include the
browser's cookies, which is how a browser page on the control plane's own origin calls the API.
`browser-token` (issue #236, SDK-04, S-1) sends a short-lived, run- or session-scoped bearer a
customer's own backend minted for its own frontend (`aw.tokens.mint`); it sends `Authorization:
Bearer` exactly as `api-key` does and, like it, never sets `credentials: 'include'` — the
workspace API key must never reach a browser, but this token was minted *for* one.
`user-token` (issue #242, SDK-10, S-22) sends the `awu_live_…` token `aw login` holds: a person,
admitted only on the person-facing routes (`me`, `workspaces`, `team.invitations`, the sharing
policy, `auth.revoke` and `workspaces.select`; ADR-0083), and like the other two bearers never
`credentials: 'include'`.

## ContractsVersionUnsupportedError

The server refused this client's contracts version: `426 contracts_version_unsupported`. It is an
`ApiProblemError`, so a handler that already branches on `status`/`code` keeps working;
`skew` adds both versions and the side to upgrade, read from the served-range response headers.
`skew` is `null` when the `426` carries no readable served range (the headers are missing or
unparsable), or one that, by this client's reading, serves it — something between the client and
the control plane answered, or the two disagree. `null` does not mean "not the control plane".

## InvalidArgumentError

The SDK refused an argument before making any request, so the server never saw it. Retrying
cannot help: fix the argument. `code` names the rule it broke — `invalid_path_segment` for an id
that is empty, `.` or `..`, which would otherwise address a different route (issue #488), or
that holds a lone UTF-16 surrogate, which cannot be percent-encoded.
