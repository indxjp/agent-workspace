Specification / implementation mismatches

INTENDED
spec.md §20.5.2 rule 5: no project-level model settings in the MVP.
→
IMPLEMENTED
projects.default_model_connection_id/default_model, UI selector, patch support and run resolution.
→
GAP
The product evolved, but the governing specification was not amended. Engineers cannot tell whether this is accepted scope or drift.
INTENDED
spec.md §20.6: publish a server-produced, redacted snapshot of the canonical subject at publish time.
→
IMPLEMENTED
POST /api/shares accepts client-provided transcript, definition, snapshot and label; ownership is checked, but canonical content is not loaded.
→
GAP
A user can publish incomplete or fabricated content and the server cannot prove the snapshot corresponds to the authorized subject.
INTENDED
spec.md §20: new, resume, list and archive sessions as a durable conversation lifecycle.
→
IMPLEMENTED
Durable session/transcript tables and APIs exist, but the user-facing navigation is a run ledger; there is no session screen or archive/restore UI.
→
GAP
The persistence model is ahead of the product model and the distinction between Session, Transcript, Message and Run is not visible to users.
