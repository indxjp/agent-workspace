SVG, icon and asset architecture

Shared shell icons

components/shell/icons.tsx is a typed table of 13 inline React SVG glyphs used by Sidebar navigation. This is the closest thing to an icon system.

Consumers: Sidebar, workspace navigation, primary shell destinations.

Feature-local SVG

Agents search and the workspace switcher each hard-code local inline SVG. They do not reuse the shell icon table, producing inconsistent ownership and duplication.

components/agents/agents-list.tsx; components/shell/workspace-switcher.tsx

Unicode controls

Many controls use raw Unicode glyphs for close, expand, navigation and status. Meaning, baseline alignment and accessible naming vary by feature.
