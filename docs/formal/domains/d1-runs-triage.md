# D1 runs triage draft

This is the step-7 classification of the D1 unit reports, [pending findings](d1-runs.md#pending-findings), and [suspicious points](d1-runs.md#suspicious-points-noticed-while-reading). The tables record the implementation at triage; the repair history below supersedes their proposed actions. It does not decide a public contract change. R-stream's real-code reproductions confirm F-096, F-100, point 4, point 13, F-101 and the empty-cursor case of point 22. Its seven theorem breadth gaps were repaired: all eight exact definition mutations now fail, and the final independent targeted recheck killed 3/3 former survivors. Security findings are kept out of this document.

`contractChange` is **yes** only where the stated smallest product fix necessarily changes a public wire contract, HTTP API shape, SDK surface, `aw` command tree, database schema or migration, or a repository-wide gate under the formal programme handover notes (maintainers' copy). A documented response code being returned correctly is **no**. For ambiguous items, a later choice of a different fix may change this flag.
