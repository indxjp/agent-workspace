# `@indx-workspace` packages 0.6.6 release notes

Release status: **published on npm on 2026-10-13.** These notes describe the lock-step 0.6.6 release of the eight
npm packages (`@indx-workspace/contracts`, `platforms`, `sdk`, `react`, `aw`, `cli`, `embedded`,
`create`), cut from a `packages-v0.6.6` tag by `.github/workflows/publish-packages.yml` once the
platform images `images-v0.6.6` are public ([release procedure](../README.md#npm-packages)).
This page says what landed since `packages-v0.6.5`; each package's `CHANGELOG.md` lists the detail
under its 0.6.6 heading.

It is a patch release with no contract change.

## Fixes

- **`run_skill_script` lists each skill's scripts.** The tool description names the scripts of every
  skill with a hint to read its `SKILL.md` first, and the `unusable_script` refusal lists the
  scripts that are available, so an agent no longer guesses a script name (#1110).

## What does not work yet

The list in [0.4.0's notes](0.4.0.md#what-does-not-work-yet) still stands.
