# `@indx-workspace` packages 0.6.7 release notes

Release status: **published on npm on 2026-10-13.** These notes describe the lock-step 0.6.7 release of the eight
npm packages (`@indx-workspace/contracts`, `platforms`, `sdk`, `react`, `aw`, `cli`, `embedded`,
`create`), cut from a `packages-v0.6.7` tag by `.github/workflows/publish-packages.yml` once the
platform images `images-v0.6.7` are public ([release procedure](../README.md#npm-packages)).
This page says what landed since `packages-v0.6.6`; each package's `CHANGELOG.md` lists the detail
under its 0.6.7 heading.

It is a patch release with no contract change.

## Changes

- **`aw runs trace` shows where a run spent its time.** Each step, tool call and result is printed as an offset from the run start, with the tool call-to-result duration; `--json` carries `at`/`calledAt`/`answeredAt`. SDK run event frames carry an optional `at` (#1115).

## What does not work yet

The list in [0.4.0's notes](0.4.0.md#what-does-not-work-yet) still stands.
