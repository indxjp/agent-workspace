# `@indx-workspace` packages 0.6.5 release notes

Release status: **published on npm on 2026-10-13.** These notes describe the lock-step 0.6.5 release of the eight
npm packages (`@indx-workspace/contracts`, `platforms`, `sdk`, `react`, `aw`, `cli`, `embedded`,
`create`), cut from a `packages-v0.6.5` tag by `.github/workflows/publish-packages.yml` once the
platform images `images-v0.6.5` are public ([release procedure](../README.md#npm-packages)).
This page says what landed since `packages-v0.6.4`; each package's `CHANGELOG.md` lists the detail
under its 0.6.5 heading.

It is a patch release with no contract change.

## Fixes

- **`aw dev` and `aw push` explain `422 agent_definition_references_missing`.** When an agent
  definition references something the server does not have, both commands now print an actionable
  hint instead of the bare error (#1100).
- **The gallery agents use `run_skill_script`, and their evals pass.** The gallery agents are
  aligned with `run_skill_script`, a failed eval is traced, and the six remaining live eval misses
  are fixed (#1100, #1105).
- **Eval traces survive progress lines.** The eval trace parser reads past progress lines, and a
  machine the maintenance agent does not know is handed off instead of guessed (#1106).
- **The docs-claims check cleans up after itself.** Each page's project is removed, and a write
  failure is reported (#1099).

## What does not work yet

The list in [0.4.0's notes](0.4.0.md#what-does-not-work-yet) still stands.
