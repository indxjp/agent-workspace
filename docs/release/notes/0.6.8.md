# `@indx-workspace` packages 0.6.8 release notes

Release status: **published on npm on 2026-10-14.** These notes describe the lock-step 0.6.8 release of the eight
npm packages (`@indx-workspace/contracts`, `platforms`, `sdk`, `react`, `aw`, `cli`, `embedded`,
`create`), cut from a `packages-v0.6.8` tag by `.github/workflows/publish-packages.yml` once the
platform images `images-v0.6.8` are public ([release procedure](../README.md#npm-packages)).
This page says what landed since `packages-v0.6.7`; each package's `CHANGELOG.md` lists the detail
under its 0.6.8 heading.

It is a patch release with no breaking contract change.

## Changes

- **An MCP connector's tools are named by the connector's key.** A Claude run names them `mcp__<connector-key>__<tool>` instead of `mcp__connector-<uuid>__<tool>` when the name is a usable slug (otherwise `connector-<id>`), so a model no longer mistypes the UUID. Stored allow and deny rules keep working and are saved in the `connector-<id>` form, so they follow a rename (#1109, #1119).
- **Policy rules show the connector's key.** The agent policy response carries an optional `connectorNames`, and the `engine_switch_would_widen` message labels refused rules the same way (#1121, #1125).
- **A stopped run no longer leaves its skill script running.** An aborted run waits for the killed script to exit before it returns (#1120, #1123).
- **Install only the engine you chose.** The engines' SDKs and the cloud SDKs are optional peers and the embedded server carries only the Next and React files it reads, so the base install goes from 1248 MB to 255 MB. `aw dev` refuses an agent whose engine is not installed and prints the `npm install` line; `npm create` and `aw init` name the engine's packages (#691, #1122, #1124).

## What does not work yet

The list in [0.4.0's notes](0.4.0.md#what-does-not-work-yet) still stands.
