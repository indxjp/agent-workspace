# `@indx-workspace` packages 0.5.0 release notes

Release status: **published on npm on 2026-10-06.** These notes describe the lock-step 0.5.0 release
of the seven npm packages (`@indx-workspace/contracts`, `sdk`, `react`, `aw`, `cli`, `embedded`,
`create`), cut from a `packages-v0.5.0` tag by `.github/workflows/publish-packages.yml` once the
platform images `images-v0.5.0` are public ([release procedure](../README.md#npm-packages)).
Each package's `CHANGELOG.md` has the detail; this page says what changed since
[0.4.0](0.4.0.md). It is a minor release: the contract changes are additive
(public-surface policy), so `CONTRACTS_VERSION` moves to 0.5.0.

## What changed

The first-hour programme (tracker #687, FH-01 to FH-13) makes `aw dev` get from `aw init` to a first
answer, tool, skill and embedded chat without leaving the terminal.

- **Tools as code run locally.** `aw dev` serves `defineTool` run files over the `aw-dev-tools`
  connector; a version that lists a code tool is refused outside `local` (`code_tool_needs_host`,
  #693).
- **Skills are synced.** `aw dev` and `aw push` sync `skills/<name>/` folders (#694).
- **The model key is checked at start.** The ready screen says a missing or rejected key once and
  tells a rejected key from an unreachable provider (`UnavailableModelConnection` gains `kind` and
  `status`, #690).
- **Live project file and secrets.** A saved `agent-workspace.yaml` is applied under `aw dev` without
  a restart (#695); secret names resolve on the server and `aw secrets replace` takes a name (#755).
- **Starters.** The `support`, `copilot` and `automation` starters write complete projects with a
  `README.md` and evals (#696).
- **`@indx-workspace/react/styles.css`** styles `<Chat/>` outside the hosted app, and a local `aw dev`
  surface admits `localhost` origins (#699).
- **Fixes.** `aw eval` explains judge failures (#736), other `aw` commands reach the port `aw dev`
  moved to (#730), `aw promote` names a bar the running `aw dev` has not applied (#734), a restart
  applies a new key or base URL (#732), and `@indx-workspace/embedded` emits its declarations (#749).

## What does not work yet

The list in [0.4.0's notes](0.4.0.md#what-does-not-work-yet) still stands.
