# `@indx-workspace` packages 0.6.9 release notes

Release status: **published on npm on 2026-10-14.** These notes describe the lock-step 0.6.9 release of the eight
npm packages (`@indx-workspace/contracts`, `platforms`, `sdk`, `react`, `aw`, `cli`, `embedded`,
`create`), cut from a `packages-v0.6.9` tag by `.github/workflows/publish-packages.yml` once the
platform images `images-v0.6.9` are public ([release procedure](../README.md#npm-packages)).
This page says what landed since `packages-v0.6.8`; each package's `CHANGELOG.md` lists the detail
under its 0.6.9 heading.

It is a patch release with no breaking contract change and no change to any package's source.

## Changes

- **The ten gallery use cases are verified live again.** The 0.6.8 live use-case run failed only because the install-live harness skipped the engine install: the engines' SDKs became optional peers in 0.6.8 (#691, #1122), so a project needs its chosen engine's packages installed. The harness now installs them (#1128). 0.6.9 re-verifies the ten use cases live against the published packages.

## What does not work yet

The list in [0.4.0's notes](0.4.0.md#what-does-not-work-yet) still stands.
