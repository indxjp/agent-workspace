# `@indx-workspace` packages 0.6.0 release notes

Release status: **images only; the packages were never published.** They ship as
[0.6.1](0.6.1.md). These notes describe the lock-step 0.6.0 release of the seven npm
packages (`@indx-workspace/contracts`, `sdk`, `react`, `aw`, `cli`, `embedded`, `create`), cut from
a `packages-v0.6.0` tag by `.github/workflows/publish-packages.yml` once the platform images
`images-v0.6.0` are public ([release procedure](../README.md#npm-packages)). Each package's
`CHANGELOG.md` has the detail; this page says what changed since [0.5.0](0.5.0.md). It
is a minor release: the contract change is additive (public-surface policy), so `CONTRACTS_VERSION`
moves to 0.6.0.

## What changed

Zero-thinking first install (tracker #760): from `npm create` to a first chat, nothing has to be
looked up or typed that the tools can offer.

- **Arrow-key setup.** `aw init` and `create` ask every choice as an arrow-key menu with the
  recommended answer preselected, show a one-line summary of each starter (`THEME_RECOMMENDATIONS[theme].summary`
  in contracts, additive), and default the file confirmation to Yes.
- **`npm create` finishes the job.** It asks the project name, offers to install dependencies and
  start the project with the package manager you ran it with, and prints next steps only for what
  was not done. On a Node below 24 it says so in one line before anything else.
- **A missing model key is a menu.** `aw dev` offers to open the provider's console, paste a key
  hidden, or skip, and prints the key line for your shell (`export`, PowerShell or cmd).
- **A ready screen you can act on.** It lists the try page, the console sign-in (URL, email and the
  file holding the first-run password) and `npx aw chat`, and offers to open the chat in the browser
  (`--open`, `--no-open`).
- **The try page is a full-height chat** with prompt chips and, without a key, a card that says what
  to do.
- **For coding agents.** `aw init` writes an `AGENTS.md` that says how to install, start in the
  background and check the project, and guarantees `.env` and `.aw/` are in `.gitignore`.
- **Smaller things.** `aw chat` with no key against a local runtime prints one line, the select menu
  measures East Asian wide characters, and the local runtime exits after the stop grace instead of
  spinning when a service never closes.
