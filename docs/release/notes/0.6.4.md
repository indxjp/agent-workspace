# `@indx-workspace` packages 0.6.4 release notes

Release status: **published on npm on 2026-10-13.** These notes describe the lock-step 0.6.4 release of the eight
npm packages (`@indx-workspace/contracts`, `platforms`, `sdk`, `react`, `aw`, `cli`, `embedded`,
`create`), cut from a `packages-v0.6.4` tag by `.github/workflows/publish-packages.yml` once the
platform images `images-v0.6.4` are public ([release procedure](../README.md#npm-packages)).
This page says what landed since `packages-v0.6.3`; each package's `CHANGELOG.md` lists the detail
under its 0.6.4 heading.

It is a patch release with no contract change.

## Fixes

- **A fresh `npm install` no longer crashes `aw dev`.** pi (`pi-coding-agent` 1.0.2) declares its
  `@earendil-works` siblings as `^1.0.2`, so a fresh install resolved the 1.2.0 siblings and
  `aw dev` failed with "does not provide an export named `MCP_TYPESCRIPT_PREAMBLE`".
  `@indx-workspace/embedded` now pins the whole pi family exactly at 1.0.2, and a test fails if pi
  gains a sibling that is not pinned (#1101, #1102).

## What does not work yet

The list in [0.4.0's notes](0.4.0.md#what-does-not-work-yet) still stands.
