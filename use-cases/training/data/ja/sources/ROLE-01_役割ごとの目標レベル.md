# ROLE-01 役割ごとの目標レベル（ヨシキリ製作所 生産技術課・架空）

スキルマップ（SKL-01）のレベル: 0 = 未経験、1 = 指導を受けてできる、2 = 一人でできる、3 = 人に教えられる。
レベルは上長が半期ごとに本人と話して記録する。人の評価や処遇を決めるものではなく、研修を選ぶためのもの。

| スキル                    | 技術員の目標 | 主任の目標 |
| ------------------------- | ------------ | ---------- |
| S-01 PLC制御              | 2            | 3          |
| S-02 治具設計             | 2            | 3          |
| S-03 なぜなぜ分析         | 2            | 3          |
| S-04 安全衛生             | 2            | 3          |
| S-05 表計算でのデータ分析 | 1            | 2          |

- S-04 安全衛生は、レベルにかかわらず、全員が年に一度「安全衛生 年次研修」を受ける。
- 研修の受講は、上長が本人と相談して決め、課長が承認する。
