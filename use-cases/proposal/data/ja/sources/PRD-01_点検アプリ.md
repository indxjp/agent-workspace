# PRD-01 ハクセキ 設備点検アプリ

タブレットやスマートフォンで設備の日常点検を記録するアプリ。

## 主な機能

- 点検表の作成: 紙の点検表と同じ項目・順序で点検表を作れる。項目は「良・否」「数値」「写真」から選ぶ。
- 設備ごとの二次元コード: 設備に貼ったコードを読むと、その設備の点検表が開く。
- 異常の通知: 「否」や基準外の数値が記録されると、指定した宛先にメールで通知する。通知はその記録の保存時に送られる。
- 電波の届かない場所: 端末に記録を保存し、通信が戻ったときに送る。

## 対応端末

iPadOS と Android のタブレット、スマートフォン。

## できないこと

- 設備のセンサーから自動で値を取り込む機能はない（手入力または写真）。
