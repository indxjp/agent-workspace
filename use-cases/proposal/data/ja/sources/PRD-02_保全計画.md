# PRD-02 ハクセキ 保全計画

設備ごとの部品交換や定期整備の予定を、計画表として管理するオプション。

## 主な機能

- 交換周期の登録: 部品ごとに、日数または稼働時間で交換周期を登録する。
- 計画一覧: 今後の交換・整備の予定を、設備別・月別の一覧で表示する。
- 点検結果との連動: PRD-01 で記録した点検結果を、設備の履歴として計画表から参照できる。

## 前提

PRD-01（設備点検アプリ）の契約が必要。
