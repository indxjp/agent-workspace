# PRD-03 ハクセキ データ連携

ほかのシステムと CSV ファイルでデータをやり取りする機能。PRD-01 に標準で含まれる。

## 主な機能

- 設備台帳の取り込み: 設備番号・設備名・設置場所の列を持つ CSV を取り込み、設備を一括で登録する。
- 点検結果の書き出し: 期間を指定して、点検結果を CSV で書き出す。列の並びは設定で変えられる。
- 自動化: 決まった時刻に、指定したフォルダとの間で取り込み・書き出しを行える。

## できないこと

- API による他システムとのリアルタイム連携は提供していない。
