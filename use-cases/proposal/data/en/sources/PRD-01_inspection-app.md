# PRD-01 Hakuseki Equipment Inspection App

An app for recording daily equipment inspections on tablets and smartphones.

## Main features

- Checklists: build checklists with the same items in the same order as the paper ones. Each item
  is pass/fail, a number or a photo.
- A 2D code per machine: scanning the code on a machine opens that machine's checklist.
- Fault notifications: when a fail or an out-of-range number is recorded, an email goes to the
  chosen recipients. It is sent when that record is saved.
- No signal: records are kept on the device and sent when the connection returns.

## Devices

iPadOS and Android tablets, and smartphones.

## What it does not do

- It does not read values from machine sensors automatically (manual entry or photo).
