# PRD-03 Hakuseki Data Exchange

Exchanges data with other systems as CSV files. Included with PRD-01.

## Main features

- Equipment register import: imports a CSV with machine number, machine name and location columns,
  and registers the machines in one go.
- Inspection result export: exports the inspection results for a chosen period as CSV. The column
  order can be configured.
- Automation: imports and exports can run at a set time, to and from a chosen folder.

## What it does not do

- It offers no real-time API integration with other systems.
