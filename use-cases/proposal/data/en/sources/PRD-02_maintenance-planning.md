# PRD-02 Hakuseki Maintenance Planning

An option that manages each machine's part replacements and scheduled servicing as a plan.

## Main features

- Replacement intervals: register an interval per part, in days or operating hours.
- Plan list: shows upcoming replacements and servicing by machine and by month.
- Linked to inspections: the inspection results recorded in PRD-01 can be viewed from the plan as
  the machine's history.

## Prerequisite

Requires a PRD-01 (Equipment Inspection App) contract.
