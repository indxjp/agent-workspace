# 休暇規程

## 第2章 年次有給休暇

### 第5条（年次有給休暇の付与）

1. 継続勤務した期間に応じて、次の日数の年次有給休暇を付与する。

| 継続勤務期間 | 付与日数 |
| ------------ | -------- |
| 6か月        | 10日     |
| 1年6か月     | 11日     |
| 2年6か月     | 12日     |
| 3年6か月     | 14日     |
| 4年6か月     | 16日     |
| 5年6か月     | 18日     |
| 6年6か月以上 | 20日     |

### 第6条（取得の手続）

1. 年次有給休暇を取得するときは、原則として取得日の3営業日前までに勤怠システムで申請し、所属長の承認を得る。
2. 年次有給休暇は半日単位でも取得できる。午前休は9時から13時まで、午後休は14時から18時までとする。
3. 急病などやむを得ない事情で事前に申請できなかったときは、出勤後2営業日以内に申請する。

### 第7条（繰越）

1. その年度に取得しなかった年次有給休暇は、翌年度に限り繰り越すことができる。

## 第3章 特別休暇

### 第9条（慶弔休暇）

1. 次の場合は、申請により特別休暇（有給）を与える。

| 事由                   | 日数 |
| ---------------------- | ---- |
| 本人の結婚             | 5日  |
| 配偶者の出産           | 3日  |
| 配偶者・子・父母の死亡 | 5日  |
| 祖父母・兄弟姉妹の死亡 | 2日  |

2. 特別休暇は、事由が発生した日から1か月以内に取得する。

### 第11条（病気休暇）

1. 私傷病により連続して4日以上休むときは、医師の診断書を人事部に提出し、年10日まで有給の病気休暇を取得できる。
