# 社会保険・福利厚生の手引き

## 1．健康保険と厚生年金

社員は入社日に、ヨシキリ製作所健康保険組合の健康保険と厚生年金に加入する。手続きは人事部が行う。

## 2．被扶養者の届出

1. 家族を健康保険の扶養に入れるときは、結婚や出生などの事実が発生した日から5日以内に、被扶養者異動届を人事部に提出する。
2. 被扶養者異動届には、次の書類を添付する。
   - 続柄を確認できる書類（住民票の写しなど）
   - 家族の収入を確認できる書類（課税証明書など）
3. 被扶養者に認定するかどうかは健康保険組合が決める。人事部は書類を確認して健康保険組合に提出する。

## 3．慶弔見舞金

1. 次の場合は、会社から慶弔見舞金を支給する。

| 事由                      | 金額     |
| ------------------------- | -------- |
| 本人の結婚                | 30,000円 |
| 子の出生                  | 20,000円 |
| 本人の入院（連続7日以上） | 10,000円 |

2. 慶弔見舞金は、事由が発生した日から3か月以内に、慶弔見舞金申請書を人事部に提出して申請する。

## 4．休業中の社会保険料

育児休業の期間中の健康保険料と厚生年金保険料は、本人の申出により人事部が免除の手続きを行う。
