# RET-01 Return deadline

- Source: Hashibami Living online shop (fictional), returns and exchanges policy, section 2
- Standard: the request date is on or before the "Return deadline" in the order record. The order system records the deadline from the delivery date; it is not recalculated here.

## Verdict

- OK: the request date is on or before the return deadline.
- Caution: the request date or the return deadline cannot be read.
- NG: the request date is after the return deadline.
