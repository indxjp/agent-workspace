# CS-03 SQLはプレースホルダで組み立てる

- 対象：コーディング規約 第3項
- ルール：SQLに値を入れるときは、プレースホルダ（`$1` など）とパラメータの配列を使う。文字列の連結やテンプレート文字列で値を埋め込まない。

## 判定

- OK：値をプレースホルダで渡している。または差分にSQLがない。
- 要注意：SQLの組み立てが差分の外にあり、読み取れない。
- NG：値を文字列の連結やテンプレート文字列でSQLに埋め込んでいる。

## 修正の書き方

``db.query('... WHERE name LIKE $1', [`%${value}%`])`` のように、値をパラメータに分ける。
