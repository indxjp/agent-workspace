# CS-04 例外を握りつぶさない

- 対象：コーディング規約 第4項
- ルール：`catch` した例外は、ログに記録して投げ直すか、型の決まったエラーとして返す。何もせずに空の値を返さない。

## 判定

- OK：`catch` がない、または例外を記録して投げ直すか、型の決まったエラーを返している。
- 要注意：記録はしているが、呼び出し元に失敗が伝わらない。
- NG：`catch` で何も記録せず、空の値や成功と同じ値を返している。

## 修正の書き方

`catch (error)` で記録したうえで `throw error;` とするか、呼び出し元が区別できるエラーを返す。
