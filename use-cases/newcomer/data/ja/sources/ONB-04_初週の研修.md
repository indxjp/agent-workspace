# 初週の研修

## 標準の予定

| 日 | 午前 | 午後 |
| -- | ---- | ---- |
| 1日目 | 入社手続き、PCの受け取り（ONB-01） | 配属先の説明 |
| 2日目 | 全社研修（会社の事業、就業規則） | 情報セキュリティのeラーニング |
| 3日目 | 配属先の業務説明（ONB-05） | メンターとの業務の同行 |
| 4日目 | 工場見学（安全教育を含む） | メンターとの業務の同行 |
| 5日目 | メンターとの業務の同行 | 上長・メンターとの振り返り |

## 注意

- 情報セキュリティのeラーニングは、5日目の終業までに修了してください。
- 工場見学の日は、作業着と安全靴を貸し出します。サイズを3日目までにメンターに伝えてください。
- 中途採用の人も、標準の予定どおりに受けます。
