# A work instruction

One heading per section, in this order. Every point ends with what it rests on: a transcript time
(`TR-01 01:25`), a clause of the safety standard (`SAF-01 2.1`) or of the manual (`EQ-03 6.2`). A
point resting on both the transcript and a clause names both.

1. **Scope** (`目的と適用範囲` / `Scope`). The machine, the task and the section, from the
   transcript's header. Who explained it and when, as the source of the procedure.
2. **Protective gear** (`保護具` / `Protective gear`). Everything the transcript names, and every
   item `SAF-01` section 1 requires for this kind of work, even when the transcript did not say it.
3. **Before you start** (`作業前の確認` / `Before you start`). The machine settings and the energy
   isolation, in the order spoken, each with its `SAF-01` section 2 clause.
4. **Steps** (`作業手順` / `Steps`). An ordered list, one action per step, in the order spoken.
   Use the operator's own wording, made plain. A value the transcript defers to the manual ("the
   value in the manual") is taken from the `EQ-xx` file and cited to it. A step a transcript leaves
   inaudible stays in place, marked `要確認` / `to be confirmed`, with the manual clause that may
   cover it named as a possibility, never as the answer.
5. **Safety notes** (`安全上の注意` / `Safety notes`). Each `SAF-01` clause that applies to a
   step, quoted in substance with its number, and the step it applies to. Lifting (section 3) and
   the trial run (section 4) are always covered when the task lifts a load or runs the machine.
6. **After the work** (`作業後` / `After the work`). Inspection hand-off and records, as spoken.
7. **Open points** (`確認事項` / `Open points`). Every `要確認` / `to be confirmed` above, and any
   question the transcript asked and left unanswered.

The document title is `作業手順書 <machine> <task>` / `Work instruction: <machine> <task>`.
