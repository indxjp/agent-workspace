# SAF-01 プレス作業安全基準

## 1 保護具

- 1.1 プレス作業では、安全靴・保護手袋・保護眼鏡を着用する。
- 1.2 金型の段取り作業では、上記に加えて保護帽を着用する。

## 2 エネルギーの遮断（施錠・表示）

- 2.1 金型の交換・調整・清掃の前に、主電源を切り、作業者本人の南京錠と「作業中・操作禁止」の札を電源盤に掛ける。
- 2.2 鍵は作業者本人が持つ。他人の錠を外してはならない。
- 2.3 空圧・油圧の残圧が抜けたこと（圧力計がゼロ）を確かめてから作業する。
- 2.4 錠を外す前に、工具の置き忘れがないこと、全員が危険範囲の外にいることを確かめる。

## 3 運搬・玉掛け

- 3.1 クレーンでの吊り上げは、玉掛けの資格を持つ者が行う。
- 3.2 吊り荷の下に立ち入らない。
- 3.3 25 kg を超える物を人力で動かすときは、二人以上で行う。

## 4 試運転

- 4.1 交換後の最初の運転は寸動で行い、金型の当たりを確かめる。
- 4.2 試運転の間、両手押しボタン以外の操作で起動しない。
