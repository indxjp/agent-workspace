# EQ-03 機械式プレス P-3 取扱説明書（抜粋）

## 6.1 金型交換の前に

- スライドを下死点の手前で停止し、運転切替スイッチを「寸動」にする。

## 6.2 クランプボルト

- 上型・下型のクランプボルトは M16。締付けトルクは 120 N·m とする。
- 締付けと緩めは対角の順に、数回に分けて行う。

## 6.3 交換後の確認

- 錠を外す前に、ボルトの締め忘れがないこと、ダイハイトの表示が金型の指定値と合っていることを確かめる。
- 試し打ちのあと、最初の製品を品質課の検査に回す。
