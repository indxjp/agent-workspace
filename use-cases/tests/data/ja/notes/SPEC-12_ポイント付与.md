# 仕様書 SPEC-12 ポイント付与（会員アプリ・株式会社コマドリ技研・架空）

版: 1.2（2026-11-16） 作成: 開発部 鶉野 遥

会員が買い物をしたときに付与するポイントの数を決める。関数の形は API-01 のとおり。

## 要件

- REQ-01 基本ポイント: 購入金額（税込・円）の 100 円ごとに 1 ポイント。100 円に満たない端数は切り捨てる。
- REQ-02 ランク: 会員ランクは `regular` と `gold` の二つ。`gold` は基本ポイントの 2 倍。
- REQ-03 金額の誤り: 購入金額が 1 以上の整数でないときは、ポイントを付与せずエラー `INVALID_AMOUNT` にする。
- REQ-04 上限: 一回の購入で付与するポイントは 5,000 まで。超えるときは 5,000 にする。
- REQ-05 ランクの誤り: ランクが `regular`・`gold` のどちらでもないときは、エラー `UNKNOWN_RANK` にする。
- REQ-06 キャンペーン: キャンペーン期間中の倍率は別紙で定める（別紙は未着）。

## 計算例

| 例    | 購入金額（円） | ランク   | 結果                  |
| ----- | -------------- | -------- | --------------------- |
| EX-01 | 99             | regular  | 0                     |
| EX-02 | 100            | regular  | 1                     |
| EX-03 | 199            | regular  | 1                     |
| EX-04 | 100            | gold     | 2                     |
| EX-05 | 250000         | gold     | 5000                  |
| EX-06 | 300000         | gold     | 5000                  |
| EX-07 | 0              | regular  | エラー INVALID_AMOUNT |
| EX-08 | 100.5          | regular  | エラー INVALID_AMOUNT |
| EX-09 | 100            | platinum | エラー UNKNOWN_RANK   |
