title: The company's tax codes
---

(A sample of the accounting manual of a fictional company, Komadori Seisakusho Co., Ltd. The tax codes are the ones its accounting system uses; they do not state how anything is treated for tax.)

## Rule

Compare the tax code of each row of the entry export with the code the table below gives for the "kind of item" of that invoice line.

| Kind of item                      | Tax code |
| --------------------------------- | -------- |
| Office supplies                   | P10      |
| Food and drink                    | P08      |
| Shipping                          | P10      |
| Cleaning and maintenance services | P10      |
| Revenue stamps and postage        | N00      |

- OK: every row's tax code matches the table.
- caution: a row's code differs from the table, or the kind of item is not in the table.

## Action

For caution, correct the row's tax code to the table's code. When the kind of item is not in the table, ask the accounting team.
