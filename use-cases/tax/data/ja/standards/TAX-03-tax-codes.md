---
id: TAX-03
title: 社内の税区分コード
---

（架空の会社「株式会社コマドリ製作所」の経理規程のサンプルです。社内の会計システムで使う税区分コードの割り当てで、税務上の取扱いを示すものではありません。）

## ルール

仕訳入力データの各行の「税区分コード」を、請求書のその明細の「品目の種類」について下の表が割り当てたコードと比べる。

| 品目の種類       | 税区分コード |
| ---------------- | ------------ |
| 事務用品         | P10          |
| 飲食料品         | P08          |
| 送料             | P10          |
| 清掃・保守の役務 | P10          |
| 収入印紙・切手   | N00          |

- OK：すべての行の税区分コードが表のコードと一致する。
- 要注意：表のコードと一致しない行がある、または品目の種類が表にない。

## 処置

要注意は、その行の税区分コードを表のコードに直す。品目の種類が表にないときは、経理部に確認する。
