# 技術メモ 部品反転装置

## 背景

組立ラインの手前で、樹脂部品の表裏を作業者が目で見てそろえている。この作業を自動にする装置を検討している。出願を考える前に、近い先行特許を調べたい。

## 構成要素

- A：ベルトコンベア上を流れる樹脂部品を、上方のカメラで撮影し、画像で表裏を判定する。
- B：裏向きと判定した部品にだけ、エアノズルから圧縮空気を吹き付けて反転させる。
- C：噴射の時刻を、コンベアのエンコーダが示す部品の位置から求める。
- D：反転のあとに2台目のカメラで判定し直し、反転に失敗した部品を別のレーンに排出する。

## 調べるときの言葉

反転、表裏、エア、エンコーダ、2台目のカメラ
