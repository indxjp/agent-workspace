# 規約改定のお知らせ文の社内ルール

- NT-01：告知日と、改定後の規約の施行日を書く。
- NT-02：変わる条ごとに、何がどう変わるかを一文で書く。
- NT-03：料金の値上げや返金しない定めの追加など、利用者に不利になる変更は、お知らせの冒頭にその旨をわかりやすく書く。「お客様に有利な変更のみ」のように、改定の中身と違う書き方をしない。
- NT-04：改定後の規約を掲載する場所（アプリ内の「規約」画面）を書く。
- NT-05：問い合わせ先（アプリ内の「お問い合わせ」と、サポート窓口のメールアドレス support@nobitaki.example）を書く。
