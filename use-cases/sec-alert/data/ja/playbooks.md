# 調査の手順書（初動）

架空の会社「ささめ電機」のセキュリティ監視チーム（SOC）の手順書から、調査の初動だけを抜き出したものです。端末の隔離やアカウントの停止は、担当者が判断して行います。

## PB-MAL-01 不審なプログラムの実行

1. EDR の画面で、親プロセスとコマンドライン、同じ端末の直前と直後の動きを確認する。
2. 通信先のアドレスが、ほかの端末からも使われていないかを確認する。
3. 元になったファイルとメールを特定し、同じメールを受け取った人を洗い出す。
4. 端末を隔離するかどうかを、担当者が SOC リーダーと決める。

## PB-AUTH-01 ログインの失敗の多発

1. 送信元のアドレスを `known-addresses.csv` と照らし合わせる。
2. 失敗した利用者名の中に、成功したログインがないかを確認する。
3. 知らない送信元からの攻撃が続くときは、送信元の遮断を担当者が判断する。

## PB-ID-02 ありえない移動・不審なサインイン

1. 二回のサインインの送信元と端末、多要素認証の結果を確認する。
2. 本人に、その時刻にサインインしたかを電話など別の手段で確かめる。
3. 管理者アカウントのときは、SOC リーダーに知らせ、セッションの取り消しを担当者が判断する。

## PB-PHISH-01 不審なメールの通報

1. 送信元のドメインとリンク先を確認する。
2. 同じメールを受け取った人と、リンクを開いた人がいないかを確認する。
3. 開いた人がいれば、その人のアカウントを PB-ID-02 で確認する。
