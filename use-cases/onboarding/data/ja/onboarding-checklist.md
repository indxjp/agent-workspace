# 入社準備チェックリスト（架空の会社「株式会社ミズナラ電機」）

人事部が管理する、入社する人ごとの準備の一覧です。入社する人一人につき、次の ONB-01〜ONB-06 を一件ずつタスクにします。期限はこの表の「期限」の列のとおりで、日付は `new-hires.csv` と `training-schedule.csv` に書かれたものを使います。

| 項目   | タスク                   | 担当                                   | 期限                                             | 内容                                                                           |
| ------ | ------------------------ | -------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| ONB-01 | アカウントの発行         | 情報システム部 宍戸 圭                 | 入社日                                           | `policies/account-policy.md` で決まるアカウントを発行する。                    |
| ONB-02 | PCと機器の準備           | 情報システム部 宍戸 圭                 | 入社日                                           | `policies/equipment-policy.md` で決まる機器を用意し、勤務地に届ける。          |
| ONB-03 | 入館証と座席の準備       | 総務部 鍛冶 美里                       | 入社日                                           | 勤務地の入館証を発行し、座席を用意する。                                       |
| ONB-04 | 初日のオリエンテーション | 人事部 薄井 遥                         | `training-schedule.csv` のオリエンテーションの日 | 就業規則、勤怠、経費の説明。                                                   |
| ONB-05 | 必須研修の受講登録       | 人事部 薄井 遥                         | 入社日                                           | 情報セキュリティ研修とコンプライアンス研修に登録する。研修の日付を備考に書く。 |
| ONB-06 | 初週の振り返り面談       | 配属先の上長（`new-hires.csv` の上長） | `training-schedule.csv` の初週の振り返り面談の日 | 上長と本人の面談。困りごとと翌週の予定を話す。                                 |

タスクの件名は「[項目] タスク：氏名（入社日 入社）」とします。例：`[ONB-01] アカウントの発行：鴫原 灯（2026-12-01 入社）`。
