# GUIDE-01 How to write an internal announcement

An announcement to all employees puts a Japanese version and an English version in one document.
The Japanese version comes first and the English version after it, and the two say the same thing.

## 1 Structure

Each language version has these headings, in this order. Leave out a heading with nothing under it.

1. Subject
2. Key points (three lines at most)
3. What changes
4. From when
5. Who it applies to
6. What we ask of you (with the deadline, if any)
7. Briefings
8. Contact
9. Not yet decided

## 2 Writing

- 2.1 Write only what the decision memo says. Add no benefits or reasons.
- 2.2 Write dates as the decision memo gives them, with the weekday when the memo has it.
- 2.3 Never write anything marked confidential.
- 2.4 For what is not decided, write "we will let you know once it is decided", with no forecast.
- 2.5 End the document with the number of the decision memo it is based on.
