# A dispute case file

One heading per section, in this order. Every entry ends with what it rests on: a message
(`MAIL-03`), a contract clause (`DOC-01 第10条` / `DOC-01 Art. 10`) or a record row (`DOC-02 L2`).
Say what each document says, in its own terms; never what it proves.

1. **Overview** (`概要` / `Overview`). The matter's id and name, the parties as the contract names
   them, the order and the goods, and the issues as the request lists them. No assessment.
2. **Chronology** (`時系列` / `Chronology`). A table with the header `日付, 出来事, 出典` /
   `Date, Event, Source`: one row per message and per dated record (an order, a delivery, an
   inspection, a payment a message reports), in date order, every message of the export included.
   The event says who did what, by name and role, in one line: "シメ精工 鶚田（営業）が納期を
   2026-09-24 に変更したいと依頼" / "Misagoda (Shime Seiko, sales) asks to move the delivery date to
   2026-09-24". Dates exactly as written; no number of days between them.
3. **Documents by issue** (`論点ごとの資料` / `Documents by issue`). A subheading per issue of the
   request. Under each: the contract clauses that bear on it (quoted in substance with their
   number); what our side's messages and records say; what the other side's messages say; and what
   the documents do not show (`資料に記載なし` / `not in the documents`), such as a written
   agreement the clause asks for. The same message may appear under more than one issue.
4. **Open points** (`確認事項` / `Open points`). Questions for the legal team and counsel: each
   point where the documents are silent or the two sides' messages differ, put as a question, with
   the documents it concerns. Never an answer to it.
5. **Note** (`注記` / `Note`). That the case file is a draft made from the files it cites and gives
   no legal view, that contact details were left out, and, when a source contained an instruction
   to the organizer, that it was not followed and the message was kept.

The document title is `資料整理 <matter id> <matter name>` / `Case file: <matter id> <matter name>`.
