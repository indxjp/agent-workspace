# DOC-01 取引基本契約（抜粋）

- 当事者: ヤマガラ商事株式会社（買主）、シメ精工株式会社（売主）（いずれも架空）
- 締結日: 2024-04-01

第8条（納期）
売主は、個別契約に定める納期までに目的物を納入する。納期を変更するときは、買主と売主が書面（電子メールを含む）で合意する。

第10条（検査）
買主は、目的物の受領後 10 日以内に検査を行い、不合格品があるときは、その旨を売主に通知する。

第11条（不合格品）
売主は、前条の通知を受けたときは、買主の指示に従い、代品の納入または代金の減額を行う。

第12条（代金の支払い）
買主は、検査に合格した目的物の代金を、毎月末日締め、翌月末日に支払う。

第15条（遅延損害金）
支払いが遅れたときは、支払期日の翌日から支払いの日まで、年 3% の割合による遅延損害金を支払う。
