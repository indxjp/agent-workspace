# 就業規則

## 第3章 勤務

### 第15条（始業・終業・休憩）

1. 始業時刻は午前9時、終業時刻は午後6時とする。
2. 休憩時間は正午から午後1時までの60分とする。
3. 業務の都合により、所属長は始業・終業時刻を前後に変更することがある。

### 第16条（時間外勤務）

1. 時間外勤務は、所属長の事前の指示または承認がある場合に限り行う。
2. 時間外勤務の申請は、勤怠システムで当日の午後5時までに行う。

## 第4章 休暇

### 第18条（年次有給休暇）

1. 入社日から6か月継続勤務した者に、10日の年次有給休暇を付与する。
2. 年次有給休暇を取得するときは、原則として取得日の3営業日前までに勤怠システムで申請し、所属長の承認を得る。
3. 急病などやむを得ない事情で事前に申請できなかったときは、出勤後2営業日以内に申請する。

### 第20条（慶弔休暇）

1. 次の場合は、申請により特別休暇（有給）を与える。

| 事由                                 | 日数 |
| ------------------------------------ | ---- |
| 本人の結婚                           | 5日  |
| 配偶者の出産                         | 2日  |
| 配偶者・子・父母の死亡               | 5日  |
| 祖父母・兄弟姉妹・配偶者の父母の死亡 | 3日  |

2. 慶弔休暇は、事由の発生日から30日以内に取得する。

## 第5章 在宅勤務

### 第22条（在宅勤務）

1. 入社後3か月を経過した者は、所属長の承認を得て、週3日を上限に在宅勤務をすることができる。
2. 在宅勤務の日は、始業時と終業時に勤怠システムで打刻する。
3. 在宅勤務では、会社が貸与した端末だけを使う。私物の端末は使わない（情報システム利用規程 第6条）。
