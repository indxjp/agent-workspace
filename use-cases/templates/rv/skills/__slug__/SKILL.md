# Reviewing to the standard

Each file in `__slug__/standards/` is one item of the standard: its id, what is acceptable, what
needs care, and the standard wording. Judge the document item by item:

- `OK`: the document says what the standard says, or something the standard accepts.
- `caution`: the document departs from the standard in a way the standard says needs care, or it
  is unclear; the fix is the standard's wording.
- `NG`: the document says something the standard says must not be accepted, or it lacks an item the
  standard requires; the fix is the standard's wording.

Cite the item's id from the file (for example `STD-01`). Quote the document's own words; never
infer what a party meant.
