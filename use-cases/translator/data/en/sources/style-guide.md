# Translation style guide

## General

- Always use the glossary's term (glossary.csv) for a word it lists.
- Keep model numbers, URLs, email addresses and the spelling of names as they are. In Japanese, write a person's name family name first.
- In Japanese, write amounts as 「19,800円」 and dates as 「2027年2月1日」.
- Add no explanation, promotional wording or note that the original does not have. Leave a word you cannot translate in the original and say so in a translator's note.

## Structure

- Keep the order and number of headings, paragraphs and bullets the same as the original, and keep the heading levels.
