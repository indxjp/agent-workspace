# 翻訳スタイルガイド

## 共通

- 訳語集（訳語集.csv）にある語は、必ずその訳語を使う。
- 型番、URL、メールアドレス、人名の表記は変えない。人名は英語では「名 姓」の順にする。
- 金額は「JPY 19,800」のように通貨コードを前に書く。日付は英語では「1 February 2027」の形にする。
- 原文にない説明、宣伝の言葉、注を足さない。訳せない語は原文のまま残し、訳者メモで伝える。

## 構成

- 見出し、段落、箇条書きの順番と数を原文と同じにする。見出しの階層も変えない。
