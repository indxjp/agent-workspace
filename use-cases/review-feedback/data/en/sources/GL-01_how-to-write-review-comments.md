# GL-01 How to write review comments (Kawasemi Kako, HR)

Review comments are text given back to the person. The reviewer writes them apart from the rating (S, A, B, C).

1. For each goal, write in this order: what the person did and what came of it (the facts), the behaviour that went well, and what to aim for next term.
2. Write only facts in the manager's notes and the person's self-assessment. Write figures as recorded; add no computed rate.
3. When the manager's notes and the self-assessment differ, do not pick one: list it apart as a point for the reviewer to check with the person.
4. Never write impressions of personality, character or attitude. Write actions and results.
5. Never compare with other employees. Never write a ranking.
6. The reviewer decides the rating (S, A, B, C) at the review meeting. Comments never give a rating or a hint of one.
7. Never write private matters unrelated to the work's results: illness, leave, family.
8. For a goal that missed its deadline, write the delay, its reason and what was done about it, as facts.
