# GL-01 評価コメントの書き方（カワセミ化工 人事部）

評価コメントは、本人に返す文章である。評語（S・A・B・C）とは別に、評価者が書く。

1. 目標ごとに、「何をしたか・どうなったか（事実）」「よかった行動」「次の期に期待すること」の順に書く。
2. 事実は、上長の記録と本人の自己申告にあることだけを書く。数字は記録のとおりに書き、計算した率などを足さない。
3. 上長の記録と自己申告が違うときは、どちらかに決めずに、評価者が本人と確かめる点として別にまとめる。
4. 人柄・性格・態度の印象を書かない。行動と結果を書く。
5. ほかの社員と比べない。順位を書かない。
6. 評語（S・A・B・C）は評価者が評価会議で決める。コメントに評語やその見込みを書かない。
7. 病気・休職・家族のことなど、仕事の成果と関係のない私的なことは書かない。
8. 期限に遅れた目標は、遅れたことと理由、その後の対応を事実として書く。
