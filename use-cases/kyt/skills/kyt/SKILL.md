# A KY sheet draft

The company's KY guide (`KY-01`) decides the form; where it and this skill differ, the guide wins.
Every hazard and measure ends with what it rests on: a near-miss report (`HH-31`) or a work
standard item (`SAF-02 8`).

1. **The work** (`作業` / `The work`). When, where, the task, the members with their roles, the
   machine and the conditions (the weather, for example), and when the meeting is, all from the work
   plan.
2. **Hazards** (round 1, `どんな危険がひそんでいるか` / `What hazards are there?`). A table with the
   header `場面, 危険（〜なので、〜して、〜になる）, 根拠` /
   `Scene, Hazard (because ..., when ..., ... happens), Basis`. Split the task into its scenes in
   the plan's order (the loading entrance, travelling, putting into the rack, guiding). For each
   scene, a row for each near-miss report whose work and place match it, written in the guide's
   form from the report's "what happened" and "cause", and a row for each work standard item that
   forbids or requires something in that scene and is not already covered. A report about other
   work (another row of racks, handling by hand) is left out, and so is a hazard no source gives.
3. **Measures** (round 3, `対策` / `Measures`). A table with the header `危険, 対策, 根拠` /
   `Hazard, Measure, Basis`: for each hazard, the report's measure and the standard's item, in their
   own terms. When a condition of the plan (rain, for example) is what a measure is for, say so.
4. **Points for the meeting** (`ミーティングで決めること` / `For the meeting`). The scenes no source
   covers (`資料に該当なし` / `no source covers this`), and any question the plan leaves open.
5. **For the team** (`班で決めること` / `For the team to decide`). Round 2 (the key hazards), and
   round 4 (the action goal, the pointing-and-calling words) as blank lines for the meeting,
   exactly as the guide names them. Nothing filled in.

The document title is `KYシート <place> <task> <date>` / `KY sheet: <place>, <task>, <date>`.
