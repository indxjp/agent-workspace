# KY-01 KYシートの書き方（セキレイ工業 安全衛生委員会）

作業の前の KY ミーティングで、班のみんなで危険を出し合い、対策と行動目標を決める。シートの下書きは班長が用意する。

1. 1ラウンド「どんな危険がひそんでいるか」: 作業の場面ごとに、危険を「〜なので、〜して、〜になる」の形で書く。
2. 2ラウンド「これが危険のポイント」: 1ラウンドの中から特に大事なものを、ミーティングで班のみんなで選ぶ。下書きでは選ばない。
3. 3ラウンド「あなたならどうする」: 危険ごとに、具体的な対策を書く。
4. 4ラウンド「私たちはこうする」: 班の行動目標と指差し呼称の言葉を、ミーティングで決める。下書きでは決めない。
5. 下書きには、危険と対策の根拠（作業基準の項目、ヒヤリハットの番号）を書く。
6. シートの最後に、作業日時・場所・作業・メンバーと、ミーティングの日時を書く。
