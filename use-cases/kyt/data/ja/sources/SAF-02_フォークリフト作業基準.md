# SAF-02 フォークリフト作業基準（セキレイ工業 安全衛生委員会）

改定: 2026-04-01

1. 運転は、フォークリフト運転技能講習の修了者に限る。
2. 運転者は、その日の作業の前に始業点検（ブレーキ、フォーク、警報装置）を行い、点検表に記入する。
3. 棚入れと棚出しでは誘導者を置く。誘導者は、運転者から見える位置に立ち、決めた合図で誘導する。
4. 誘導者は、フォークリフトの後方と旋回の範囲に入らない。
5. フォークやパレットの上に人を乗せない。
6. 荷を高く上げたまま走行しない。走行するときは、フォークを床から 15〜20 cm に下げる。
7. 床が濡れているときは徐行する。雨の日は、搬入口に滑り止めのマットを敷く。
8. 棚に差し込む前に、パレットの破損と、棚の差し込み位置の空きを確認する。
9. 歩行者通路と交わる場所では一時停止し、左右を確認する。
10. 作業者は、ヘルメットと安全靴を着用する。
