# 2026年度 第2四半期 決算説明資料

## 1. セグメント別の業績（第2四半期累計）

| セグメント | 売上高  | 前年同期 | 営業利益 | 前年同期 |
| ---------- | ------- | -------- | -------- | -------- |
| 電子材料   | 236億円 | 214億円  | 25億円   | 24億円   |
| 機能樹脂   | 176億円 | 174億円  | 13億円   | 16億円   |

## 2. 営業利益の増減要因（前年同期の40億円から当期の38億円へ）

| 要因             | 影響   |
| ---------------- | ------ |
| 販売数量の増加   | +6億円 |
| 価格改定         | +3億円 |
| 原材料価格の上昇 | −9億円 |
| 固定費の増加     | −2億円 |

機能樹脂では、原材料価格の上昇を価格改定で補いきれなかった。

## 3. 下期の取り組み

- 機能樹脂の価格改定を2026年10月から追加で実施している。
- 通期の業績予想は据え置いた。

## 4. 設備投資

- 通期の設備投資計画は60億円で、上期の実績は26億円である。
- 新工場（第2期）は、2027年度中の稼働を予定している。

## 5. 株主還元

中期経営計画では、配当性向30%を目安に安定した配当を続ける方針である。
