# シギノ・リンク かんたん操作ガイド（草稿）

（本書は架空のサンプルです。実在の会社・製品・人物とは関係ありません。作成: 株式会社シギノ計装 サポート部）

## 1. はじめに

このガイドは、シギノ・リンクを初めて使うユーザーのための手引きです。

## 2. ログオンする

ブラウザでシギノ・リンクを開き、メールアドレスとパスワードを入力してログオンします。パスワードを忘れたときは、管理者にリセットを依頼してください。

## 3. ホーム画面を見る

ログオンするとホーム画面が開き、登録したセンサーの最新の計測値が一覧で表示されます。

## 4. 警報を設定する

センサーごとに閾値を決めておくと、計測値がそれを超えたときに警報がメールで届きます。設定できるのは管理者だけです。
