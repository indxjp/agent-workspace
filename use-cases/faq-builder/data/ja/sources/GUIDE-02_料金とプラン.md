# ミズナラ勤怠 料金とプラン

## 1. プラン

| プラン       | 月額（1名あたり・税抜） |
| ------------ | ----------------------- |
| スタンダード | 300円                   |
| プレミアム   | 500円                   |

## 2. 無料トライアル

- 申し込みから14日間、すべての機能を無料で使える。
- トライアルが終わっても自動で有料にはならない。プランを選ぶまで利用は止まる。

## 3. 月の途中で社員を追加したとき

- 追加した月から、1名分の月額を加算する。日割りの計算はしない。

## 4. 解約

- 解約した月の末日まで使える。支払い済みの月額は返金しない。
