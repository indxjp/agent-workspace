# ミズナラ勤怠 管理者ガイド

## 1. 管理者のパスワード

- パスワードを忘れたときは、ログイン画面の「パスワードをお忘れの方」から、登録したメールアドレスに再設定のメールを送る。メールのリンクの有効期限は30分である。
- 再設定のメールが届かないときは、迷惑メールのフォルダを確認する。それでも届かないときは、サポート窓口に連絡する（GUIDE-03）。
- パスワードを5回続けて間違えると、アカウントが15分ロックされる。15分たってからログインし直すか、パスワードを再設定するとロックが解除される。

## 2. 月次CSV出力

- 勤怠データは「集計」メニューの「月次CSV出力」から、月ごとにCSVで出力する。
- 「列の設定」で、出力する列とその順番を変えられる。
- 文字コードは UTF-8 と Shift_JIS から選べる。

## 3. スマートフォンでの打刻と位置情報

- 位置情報の記録は、管理者が「設定」の「打刻」で有効または無効にする。初期設定は無効である。
- 記録されるのは打刻した時点の位置だけで、勤務中の移動は記録しない。
