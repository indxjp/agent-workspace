# Checking an NDA against the standard

The standard is eight items, one file each in `nda/standards/`: `NDA-01` definition of confidential
information, `NDA-02` exceptions, `NDA-03` use beyond the purpose, `NDA-04` disclosure to third
parties, `NDA-05` term and survival, `NDA-06` return and destruction, `NDA-07` damages, `NDA-08`
governing law and jurisdiction. Each file's rule says which wording is `OK`, which is caution
(`要注意`) and which is `NG`. Apply the rule as written; it is the company's decision, not yours.

For each item:

1. Find the NDA's clause on the same subject, by its heading or its content. A subject the NDA has
   nowhere is `missing` (`欠落`); its verdict is what the rule says for an absent clause.
2. Compare what the clause says with the rule, point by point. Quote the clause's own words.
3. Take the verdict the rule names for that wording. When the rule names none for it and the clause
   says what the standard clause says, it is `OK`.
4. For caution and `NG`, the suggested fix is the item's standard clause with the NDA's own party
   names and defined terms. For `OK`, leave it empty.

Read the whole sentence of a clause: a proviso ("ただし" / "provided that", "however") can change
the verdict. Two subjects in one clause (for example a term and the survival of the duty) are each
judged under their own item.
