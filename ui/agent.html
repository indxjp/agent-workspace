Changing runtime: Standard Sandbox → Azure Sessions

Docker → Azure Container Apps dynamic sessions
⚠
Domain allowlist is not supported on this runtime. “Restricted” becomes all-or-nothing egress, enforced by our proxy rather than by the platform.
⚠
Sessions on this runtime end after the pool cooldown (10 minutes idle). Longer conversations are resumed on a fresh sandbox and the workspace is rehydrated from object storage.
✕
This agent uses a local command connector (Filesystem MCP). This runtime has no outbound network for package downloads. Bundle the connector into the runtime image, or switch it to a remote URL.

What survives the switch

Workspace filesKeptObject storage is the source of truth; the new sandbox is hydrated
Skills, connectorsKeptMaterialised into the workspace at launch
Claude sessionKeptSession state in PostgreSQL, resumed with resume
Anything else in the old sandboxLostSandboxes are disposable by definition

Switching back restores the previous behaviour exactly. This change is recorded in the audit log.
