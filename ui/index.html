Agent Workspace — UI specification

Every screen of the self-hosted control plane for the Claude Agent SDK, as clickable HTML. No build step, no network, no framework — open any file directly. Section numbers refer to docs/spec.md.

Conventions this prototype fixes

Progressive disclosureEverything a normal operator needs is visible; maxTurns, allowedTools, raw MCP JSON, driverConfig and SDK options live behind an Advanced disclosure. (§43)
Honest capabilitiesNo screen claims parity. Model and runtime differences are stated as ✓ native / ~ approximated / — unsupported, in the same words in the picker, the review step and the matrix. (§12, §14.5)
Visible runtimeThe top bar of every screen names the driver in force, and an unverified runtime cannot be assigned. (A.3, §14.8)
SecretsShown once at creation, never again; referenced by name in configuration; never in an export, a definition share or a published transcript. (§23, §20.6)
SharingPrivate → workspace → public link, on agents, chats, projects and skills. Snapshots are redacted at creation, links are revocable, runnable links are capped and killable. (§20.6)
No dashboardThe home page is a chat box. Numbers appear where a decision needs them, not as a landing page. (§45)

Light and dark themes follow the operating system setting. Files: 26 HTML pages, assets/app.css, assets/app.js.
