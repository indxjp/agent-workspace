Policy

Block the local runtime for deployed agents
“This machine” has no isolation and stays available for development only
Require a verified runtime before deploying
An agent cannot be deployed onto a profile that has never passed create → echo → destroy
Warn on capability gaps instead of blocking
Off means a model or runtime that cannot meet the agent’s requirements is refused outright
Store assistant thinking in run history
Off means thinking blocks are streamed to the browser but never persisted
