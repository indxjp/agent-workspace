# {{agentName}}

An agent that answers from your documents. It is a small start: one example skill, `cite-sources`,
and two eval cases. For complete, runnable examples, create a project with another theme:

- `npm create @indx-workspace@latest -- --theme support` shows a skill and surface parts.
- `npm create @indx-workspace@latest -- --theme automation` shows a code tool and an API tool.
- `npm create @indx-workspace@latest -- --theme copilot` shows a React page.

Run it with `npm install && npm run dev`; `npx aw eval` runs `evals/{{agentName}}.yaml`.
