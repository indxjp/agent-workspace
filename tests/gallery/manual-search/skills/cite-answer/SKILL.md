# 出典つき回答の書き方

- 回答は結論を1〜2文で先に書き、続けて根拠を箇条書きにする。
- 各根拠の末尾に出典を〔文書名 p.ページ §節〕で書く。例: 〔油圧ユニット保守マニュアル p.12 §3.2〕
  - 文書名は `search_manual` が返す `source` をそのまま使う。
  - ページと節は `read_section` が返す `citation` をそのまま使う。言い換えない。
- 出典のない文を書かない。複数の文書が矛盾するときは両方を出典つきで示し、
  「改訂日の新しい方を優先してください」と添える。
- 根拠が見つからないときは次の文で答える:
  「該当する記載が見つかりませんでした。設備保全課（内線 4410）にお問い合わせください。」
