# 見積原価の計算

金額は自分で計算しません。部品仕様と ERP の `getRate` が返したレートを、そのまま
`scripts/estimate.mjs` に渡し、出力を回答の最後に貼ります。シェルを使わず、`run_skill_script`
ツールで動かします。

```json
{
  "skill": "cost-model",
  "script": "estimate.mjs",
  "args": [
    "quote",
    "--spec",
    "<部品仕様 JSON>",
    "--rate",
    "<getRate の出力 JSON>",
    "--orders",
    "SO-2024-0412,SO-2025-0108"
  ]
}
```

- `--spec` は図面から読み取った部品仕様（または依頼文の部品仕様 JSON）をそのまま使う（材質・外形 長さ×幅・板厚・穴数・穴径・曲げ数・数量）。
- `--rate` は `getRate` の出力をそのまま使う。数値を書き換えない、丸めない、別の材質のレートを使わない。
- `--orders` は `getOrder` で実際に読んだ同じ材質の受注番号だけをカンマ区切りで渡す。類似実績がなければ付けない。
- スクリプトが `estimate refused:` で止まったら（板厚がレート表の範囲外など）、見積を作らず理由を書く。

## 式（1個あたり）

| 項目 | 式 |
| --- | --- |
| 材料費 | 長さ×幅×板厚(mm³)÷1000 → cm³ × 比重 ÷1000 → kg × 材料単価(円/kg) ÷ 歩留まり |
| 切断費 | (2×(長さ+幅) + 穴数×π×穴径) mm ÷1000 → m × 板厚に応じた切断レート(円/m) |
| 曲げ費 | 曲げ数 × 曲げ単価 |
| 段取り費 | ロット段取り費 ÷ 数量 |
| 単価 | 原価合計 × (1 + 利益率) |

## 丸め（円）

1. 材料費・切断費・曲げ費は1円未満を四捨五入。
2. 段取り費は1円未満を切り上げ（ロットの段取り費を必ず回収する）。
3. 原価合計は丸めた4項目の和。
4. 単価は10円未満を切り上げ。
5. 金額は単価×数量。すべて税抜。

ブランクは外形どおりとし、ネスティング・端材価値・表面処理は含めない。表面処理や研磨が
仕様にあるときは「別途」と書く。

## 回答に貼るもの

`quote` の出力をそのまま回答の最後に貼る。類似実績がなければ先頭に `類似実績なし` の行が付き、
続けて ```json ブロックが1つ出る。

```json
{ "breakdown": <estimate.mjs の内訳>, "similarOrders": ["SO-2024-0412", "SO-2025-0108"] }
```

- 書き換えない、コンパクトに整形し直さない。値引きや端数調整を頼まれたときも省かない
  （バックエンドはこのブロックを読み直して単価を再計算する）。
- `similarOrders` は `--orders` に渡した番号で、`getOrder` で実際に読んだものだけ。

Bash が使える実行では、内訳だけを返す標準入力の形（`echo` で JSON を `node scripts/estimate.mjs` に
パイプする）も使えるが、その場合はブロックを自分で組み立てることになるので、`quote` を使う。

## 確度の目安（バックエンドが同じ規則で判定する）

- 高: 同じ材質の類似実績が2件以上あり、見積単価が実績単価の中央値から ±15% 以内。
- 中: 類似実績が1件以上あり、±30% 以内。
- 低: 類似実績なし、または ±30% を超える。
