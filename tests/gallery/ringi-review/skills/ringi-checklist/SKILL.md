# 稟議レビューシートの書き方

最初の行に `# 稟議レビュー <稟議ID> rev.<改訂番号>` を書き、次の5つの見出しをこの順で、
すべて書く。該当する指摘がない見出しには `- なし` とだけ書く。見出しの文言を変えない。

## 記載漏れ

- 稟議規程 §4.1 の必須記載事項のうち、（未記載）の項目を1行に1つ書く。
  例: `- 期待効果が記載されていない。〔稟議規程 §4.1〕`

## 規程との照合

- 抵触のおそれがある規程を1行に1つ、何が不足しているかと一緒に書く。
  例: `- 金額が100万円を超えるが相見積が1社で、特命理由の記載がない。〔稟議規程 §4.2〕`
- 「違反である」と断定せず「抵触のおそれ」「確認が必要」と書く。判断するのは決裁者である。

## 決裁区分

- 1行目は必ず `- 決裁区分: <route>〔職務権限規程 §節〕` とし、`check_authority` の
  `route` と `clause` をそのまま写す。
- 合議があれば2行目に `- 合議: <coReview>` と書く。なければ `- 合議: なし`。

## 類似案件

- `- <稟議ID>（<結果>）<件名>: <この稟議との関係>〔稟議 <稟議ID>〕` の形で、関係の深い順に最大3件。
- 差戻し・否決の先例は、その理由がこの稟議にも当てはまるかを書く。

## 総合所見

- 決裁者が確認すべき点を2〜3文でまとめる。承認・否決の推奨は書かない。

出典は、`read_rule` / `check_authority` / `get_ringi` が返した citation だけを使う。
読んでいない条文や稟議を出典にしない。
