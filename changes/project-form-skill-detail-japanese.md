- The project form, a project's detail screen and a skill's detail screen are in Japanese for a
  Japanese reader: the project form's fields, hints, visibility choices, default agent and default
  model (on the create form and the detail screen), the detail screen's heading, archived notice,
  assigned resources, Cancel and Save changes, the archive and restore section and its
  confirmation (including the count of affected sessions and runs), the discard-changes prompt,
  and the skill detail screen's labels, files and revisions line, Back and Save changes. Each
  screen carries `lang`. Project, agent, file, connector, model connection and skill names, a
  skill's stored text, the `aw skills publish` command and the server's own messages are shown as
  they are. English is unchanged (UX-15 in #2086).
